# Color Prediction Model

This is a simple neural network that inputs the red, green, blue values of a color and outputs an approximate name of that color.

There is no model data here.

## Usage

To add data, run `data.py`, open `127.0.0.1:8080` on your browser and follow the instructions there.

To train the model, run `train.py`.

To predict new values, run `predict.py` and open `127.0.0.1:8080` on your browser. The webpage will prompt you to enter a color.
